# MongoDB Express Chat App

A simple chat application built using Node.js, Express.js,
MongoDB, Mongoose and EJS.

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- CSS

## Features
- Create new chats
- View all chats
- Edit existing chats
- Delete chats
- RESTful routes
- MongoDB database integration

## Installation

1. Clone this repository:

   git clone YOUR_REPOSITORY_URL

2. Navigate to the project:

   cd Mongo3

3. Install dependencies:

   npm install

4. Start the application:

   node index.js

5. Open localhost:8080 in your browser.
